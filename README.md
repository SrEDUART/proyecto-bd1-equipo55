## Descripción general

El proyecto contempla el diseño, normalización e implementación de una base de datos relacional para la gestión integral de una ferretería multisucursal.

El sistema permite representar la información necesaria para administrar sucursales, productos, categorías, inventario, clientes, usuarios, ventas, detalles de venta y métodos de pago.

El desarrollo comprende el modelado conceptual mediante un Diagrama Entidad-Relación (DER), su transformación al modelo relacional con claves primarias y foráneas, y el proceso de normalización hasta la Tercera Forma Normal (3FN).

## Etapas del proyecto

Actualmente se encuentra desarrollada la **Etapa II: Modelado Conceptual y Lógico**, que incluye:

- Diagrama Entidad-Relación.
- Transformación al modelo relacional.
- Definición de claves primarias y foráneas.
- Normalización a 1FN, 2FN y 3FN.
